Browser QGIS · 网页接入示例

这一页本身就是接入示范：它不是服务渲染的静态页面，而是用 fetch() 实时调用接口取数据、拼结果。下面每一段都可以直接复制到你自己的网页里。

服务地址… 接口文档 /docs 控制台 /
跨域已开启（CORS allow_origins: ["*"]），因此其它网页直接 fetch("http://<本机IP>:8848/api/...") 即可， 不需要任何服务端代理。局域网内其它设备用本机 IP 访问同一端口。

1 · 列出数据集与图层

// 列出所有数据集
const r = await fetch(`${BASE}/api/datasets`);
const { datasets } = await r.json();

// 某个数据集的图层清单（含类别表、坐标系、范围）
const d = await (await fetch(`${BASE}/api/datasets/demo_mine`)).json();
const layers = Object.values(d.layers);
（点击「运行」查看实时返回）

2 · 点查询：点击位置拿到地类

// 一次请求同时拿到所有栅格图层的取值 + 矢量命中
const res = await fetch(
  `${BASE}/api/query/point?lon=112.48&lat=39.685`
).then(r => r.json());

res.rasters.forEach(r => console.log(r.layer_id, r.class_name ?? r.value));
（点击「运行」查看实时返回）

3 · 范围统计：各类地面积多少

// 给一个经纬度范围，返回每一类的像元数与面积（公顷）
const stats = await fetch(
  `${BASE}/api/rasters/demo_mine/landuse_2020/bbox` +
  `?minx=112.40&miny=39.62&maxx=112.56&maxy=39.75`
).then(r => r.json());

stats.classes.forEach(c =>
  console.log(c.name, c.area_ha.toFixed(1), 'ha', (c.ratio*100).toFixed(1)+'%'));
（点击「运行」查看实时返回）

4 · 渲染成图片直接贴到网页

// 服务端直接出 PNG，当成普通图片用即可
<img src=`${BASE}/api/render/raster/demo_mine/landuse_2020.png?width=800` />
// 也可以当作 XYZ 瓦片源，直接喂给 Leaflet / MapLibre
const tiles = L.tileLayer(`${BASE}/api/tiles/demo_mine/landuse_2020/{z}/{x}/{y}.png`, {
  minZoom: 8, maxZoom: 16
}).addTo(map);
（点击「运行」查看瓦片地址与状态）

5 · 矢量要素：拿 GeoJSON 自己画

// 返回标准 GeoJSON，坐标系已统一为 WGS84
const gj = await fetch(
  `${BASE}/api/vectors/demo_mine/aoi/features?limit=100`
).then(r => r.json());

// Leaflet
L.geoJSON(gj).addTo(map);
// MapLibre
map.getSource('aoi').setData(gj);
（点击「运行」查看实时返回）

接口速查

接口说明
GET /api/datasets数据集列表
GET /api/datasets/{id}数据集详情（全部图层与类别表）
GET /api/datasets/{id}/overview各地图层的地类面积概览
POST /api/datasets/rescan重新扫描数据目录
GET /api/rasters/{ds}/{layer}/point点查询（lon / lat）
GET /api/rasters/{ds}/{layer}/bbox范围统计（minx/miny/maxx/maxy）
POST /api/rasters/{ds}/{layer}/polygon多边形统计（body 传顶点环）
GET /api/rasters/{ds}/{layer}/area地类面积
GET /api/rasters/{ds}/{layer}/histogram像元直方图
GET /api/vectors/{ds}/{vec}/features要素 GeoJSON（bbox / limit / where）
GET /api/vectors/{ds}/{vec}/stats矢量统计
GET /api/vectors/{ds}/{vec}/hit点命中
GET /api/render/raster/{ds}/{layer}.png栅格出图
GET /api/render/vector/{ds}/{vec}.png矢量出图
GET /api/render/combined/{ds}.png多图层叠加出图
GET /api/tiles/{ds}/{layer}/{z}/{x}/{y}.pngXYZ 瓦片
GET /api/query/point栅格 + 矢量综合点查询
GET /api/meta · GET /healthz服务信息与健康检查
