怎么用 Browser QGIS

把 PyQGIS 内核搬到网页上的通用 GIS 工作台：浏览器里就是 QGIS 的样子（菜单栏、两排工具栏、 图层树、右侧属性面板、状态栏），底下跑的是真的 QGIS 3.44，440 个 Processing 算法都能用。

三分钟上手

1
把服务起起来。在项目目录双击 start.bat（或运行 launcher.bat 用图形界面管服务）。等窗口里出现「就绪」再往下走 —— 启动要十几秒， 这期间接口会回 503，是正常的。
2
打开控制台。浏览器访问 http://127.0.0.1:8848/； 局域网内别的机器用本机 IP，例如 http://192.168.1.20:8848/。 第一次要登录 —— 登录页上有一块「共享超级账号」，写着用哪组口令直接登； 没有的话看项目目录的 data/admin_password.txt。
3
加数据。两条路：把 .tif / .geojson / .gpkg / .shp 直接拖到地图上（最省事），或者用 ＋ → 本地文件 选文件上传、再从「服务器共享数据」里勾选加入。
4
干活。点地图要素做识别；用顶部第一排的导航工具缩放； 右侧切到工具箱跑 Processing 算法（缓冲区、裁剪、重投影…），跑完的结果能一键加回地图。
数据格式：栅格 .tif/.tiff/.img/.vrt； 矢量 .geojson/.gpkg/.shp/.gml/.kml。 矢量/栅格不用自己分 —— 上传后服务端按扩展名自动识别，混着传也行。

界面分区

顶部菜单栏

文件：添加图层 / 重新扫描数据目录 / 清空地图 / 服务信息
编辑：移除选中图层 / 清除识别结果
视图：缩放至图层、缩放到选择、全图、上一个/下一个范围、地图提示
图层：图层属性、缩放至图层、移至最前/最后、移除图层
帮助：本帮助 / 关于本服务

两排工具栏（QGIS 桌面版同款）

第一排 · 地图导航：平移、放大、缩小、缩放到图层、缩放到选择、全图、 上一个范围、下一个范围、按比例缩放（1:N）、地图提示、刷新
第二排 · 图层 / 编辑 / 选择：添加图层、打开属性表、字段统计 ‖ 切换编辑、保存编辑、放弃编辑、添加要素、删除选中、字段计算器 ‖ 全选、取消选择、反选、按表达式选择、按空间关系选择

左栏：图层

当前地图上的图层树。＋ 加图层、↑↓ 调整叠放顺序、× 移除。 点一行选中它，右键出菜单（缩放至图层 / 图层属性 / 移除图层）。

地图左上角浮动条

就是 QGIS 的 Map Tools：识别（点图查要素）、测距、测量面积。 导航类的按钮都在顶部第一排，两边不重复。

右栏：九个面板

识别结果（点图命中的要素）、图层属性（常规/符号系统/透明度/源）、 工具箱（Processing）、属性表、统计、选择、 书签、日志、处理历史。 管理员登录后还会多一页「管理员」（账号 / 空间 / 审计 / 配置）—— 普通用户看不到这一页。

底部状态栏

光标坐标、实体刻度比例尺（1:N）、比例尺、CRS、图层数、QGIS 版本、状态提示。

面板大小可以拖着改：左右侧栏的宽度、工具箱里「算法列表 / 参数区」之间的高度、 「添加图层」对话框的大小和左侧数据源树的宽度，都拖边框就能改。 把手能聚焦，← → 微调， 双击恢复默认；改完会记住，刷新还在。

常用操作

加图层

  • 拖到地图上：文件直接拖进地图窗口就上传并加载（QGIS 的拖放行为）。
  • ＋ → 本地文件：选文件 → 选空间（个人/共享）→ 「打开」。
  • ＋ → 服务器共享数据：服务器上已有的图层，勾选后「打开」直接加载。
  • ＋ → XYZ 瓦片 / WMS：填 URL 模板，瓦片不进 Processing 的输入。

查看数据

  • 识别：点地图 → 右栏「识别结果」列出命中的要素。
  • 属性表：右栏 → 切图层、下拉选图层、过滤表达式、分页看行。
  • 统计：选图层后按字段给计数、均值、中位数、分组高频值。

编辑

  • 工具栏「切换编辑」进入编辑模式 → 添加要素 / 删除选中 → 保存编辑提交； 放弃编辑回滚（没保存的改动会丢）。
  • 字段计算器：按表达式批量写字段（中文字段名要用双引号包起来）。

选要素

  • 全选 / 取消选择 / 反选；按表达式选择（QGIS 表达式语法）； 按空间关系选择（相交、包含、位于内部…）。
  • 选中的要素在地图上高亮，缩放到选择在第一排。

书签

「书签」面板 →「新建」把当前地图范围存成一个书签，点书签名直接飞过去。

工具箱（Processing）

右栏 → 工具箱，或者顶栏第二排的「工具箱」按钮。里面是 QGIS 的 440 个 Processing 算法 （缓冲区、裁剪、重投影、栅格统计、矢量化…），行为和 QGIS 桌面版一致。

  1. 在上方搜索框搜算法名 —— 中文名和英文名都能搜（搜 buffer 和搜 缓冲区 结果一样）。
  2. 点中一个算法，下方自动生成参数表单：图层下拉、数字框、枚举下拉…
  3. 填完点「运行算法」。作业在后台跑，状态栏和「处理历史」里能看到进度。
  4. 跑完的结果可以直接加到地图，也可以下载。
枚举参数的取值要按界面显示的中文来（比如「圆角」），提交时服务端会自己认； 栅格输入需要先在地图上加好图层。

Python 控制台与插件

这两样都是把服务端「打开」给你。它们都等于在数据服务器上执行任意代码， 所以能不能用由服务端的配置决定 —— 本机这套默认对所有登录用户开放； 看不到这一节，说明你的账号没有这个权限。

Python 控制台

「视图 → Python 控制台」（快捷键 Ctrl+`） 拉起一个贴底的抽屉，和 QGIS 桌面版的 Python Console 一个位置。

>>> project().mapLayers().keys()      # 直接摸当前工程
>>> layer = QgsVectorLayer("data/shared/example/x.gpkg|图层名", "x", "ogr")
>>> print(layer.featureCount())
>>> print(QgsProject.instance().crs().authid())
  • 命名空间是持久的：上一次定义的变量还在，可以接着用。
  • 按人隔离：A 用户的变量不会出现在 B 用户那儿。
  • 能摸真 QGIS：代码在 QGIS 工作线程上跑，图层、要素、算法都能用。
  • 危险调用被挡住：os._exit() / os.abort() / os.exec*() 会直接结束（或替换）服务进程，控制台里会报错拦下 —— 防的是手滑。
  • Enter 执行、Shift+Enter 换行，可以用 ↑ ↓ 翻历史命令。
代码跑在 QGIS 工作线程上，Python 没法中断一个正在跑的线程 —— 死循环的代码超时后接口会返回，但那个线程还占着，QGIS 相关的请求会跟着卡住。 遇到这种情况只能重启服务。

插件

插件是装在 plugins/ 下的一个 Python 包，能往服务里加：

能力说明
右栏面板插件自己提供内容，右栏多一个标签页
菜单项菜单栏多一项
自己的接口注册 REST 端点，前端或其它系统都能调
Processing 算法自动出现在工具箱里，和 QGIS 自带的并列

怎么装：把插件目录拷进 plugins/ 后重启服务； 或者在网页上「插件 → 安装插件」上传一个 .zip（像 QGIS 插件管理器）。

谁能管：装 / 启停 / 重载 / 卸载只有管理员能做 —— 插件是服务端代码。 改完代码可以「重载」，不用重启服务。

项目自带一个示例插件 plugins/gisds_hello/， 把插件能做的每件事都用了一遍，可以拿来当模板。

数据与空间

空间谁能看到谁能写位置
共享空间所有登录用户所有登录用户data/shared/<数据集>/
个人空间只有本人只有本人data/users/<用户ID>/<数据集>/
  • 一个目录 = 一个数据集；一个数据集里可以放多个文件（一个 .tif， 或 .shp + .dbf + .shx + .prj 一套）。
  • 管理员能看见所有空间；免登录模式下所有人都只共享空间。
  • 文件放在磁盘上直接也会被扫到（改完目录点菜单「文件 → 重新扫描数据目录」即可）。

图形启动器

不想碰命令行就双击 launcher.bat。它能：

  • 启停 REST 服务，并显示「停止中 / 启动中 / 就绪」三态；
  • 管理用户（建号、改口令、停用、删除）；
  • 浏览与上传文件：每个数据空间都能看、能传、能下载、能删（也能单独开一个文件浏览器窗口）。

顶栏「服务密钥」是多机部署的救生圈：管理员人在另一台机器、忘了 admin 口令时， 填服务端 config.json 里的 api_key 就能进去重置任意账号的口令。

常见问题

导入的图看不见 / 地图上什么都没有

  • 先刷新页面（Ctrl+F5 强刷）。
  • 栅格要登录才能出图；没登录时接口回 401，界面会是一片空白且不报错。
  • 看看状态栏有没有告警，比如「图层 xxx.tif 没有坐标系信息，已按 EPSG:4326 解释」。 没有 CRS 定义的 tif 现在会自动按 WGS84 解释并提示；如果它本该是投影坐标， 带上正确的 .prj 或用 gdalwarp 转一下。
  • 图层加上了但位置不对：看状态栏坐标对不对，范围不对就是坐标系的问题。

.shp 上传了却「没被识别成图层」

shapefile 是一组文件：.shp .dbf .shx .prj 缺一不可，只传 .shp 是打不开的。把整套一起选中上传即可。 界面会明确告诉你「文件已保存但没能识别成图层」。

遥感影像打开后整片发紫

真彩色影像（Sentinel-2 这类多波段）现在按 QGIS 桌面版的方式合成显示， 不会再发紫。

  • 图层属性 → 「数据类型」写着「真彩色（RGB 合成）」就是这种影像。
  • 符号系统面板里第一项是「真彩色（QGIS 默认）」，别改成单波段的那些 —— 单波段只看第 1 个波段，绿色通道会被压没，图就成了一片紫。

忘了管理员口令

  • 如果这台服务配了共享超级账号，登录页上会有一块「共享超级账号」， 上面直接写着账号和口令（见上面「管理员分区与共享账号」）。
  • 项目目录的 data/admin_password.txt 记着当前有效口令。
  • 命令行：run-qgis-python.bat -m gisds set-password admin。
  • 远程（多机部署）：启动器顶栏「服务密钥」→ 填 config.json 里的 api_key。

服务起不来 / 端口被占

8848 被别的程序占了就换端口：改 config.json 的 port，或设环境变量 GISDS_PORT。启动器有就绪三态，「启动中」别当成失败。

改了前端，页面没变

以前要 Ctrl+F5 强刷，现在网页资源都带 Cache-Control: no-cache， 普通刷新就会校验，改了立刻生效。

中文图层名 / 分类显示成英文

算法名与分类名来自 QGIS 官方翻译包；没装翻译包时显示英文原名。 分类表在数据集目录的 metadata.json 里可以自己写。

管理员分区与共享账号

共享超级账号

这台服务可以配置一个所有人都能用的管理员账号：在 config.json 的 super_admin_password 里填一个口令即可 （默认是空的，也就是不开）。开了之后登录页上会有一块「共享超级账号」 直接写着账号和口令，点「填入表单」就能登录。

请当心这个账号。拿到这组口令的人就是管理员 —— 能开号、能停用别人的账号、 能删数据、能跑 Python。服务默认监听 0.0.0.0（局域网内谁都能访问）， 所以这条口令等于把管理员身份发给整栋楼。要收紧就把 config.json 里的 super_admin_password 清空， 或把服务收到内网 / 反代后面。

管理员分区（右栏最后一页）

用管理员账号登录后，右栏多一页「管理员」。普通用户看不到这一页 —— 不是点了报错，是压根不渲染。

分区能干什么
用户列出全部账号；新建；设为管理员 / 降为普通用户； 停用 / 启用；改密码；删除（两步确认，不能删自己）
空间各空间登记在册的数据集、图层数与磁盘路径
审计最近 200 条审计日志（登录、改密、建号、删号…）
配置监听地址、数据根目录、上传上限、控制台开放模式， 以及共享超级账号的风险提示

「用户」分区顶部有一条醒目提示：共享超级账号开着的时候，会直接写明 「同网段任何人拿它登录都是管理员」，并告诉你要收紧该改哪个配置项。

自己跑一遍自检

改完代码想确认没弄坏东西，在项目目录跑：

powershell -ExecutionPolicy Bypass -File tests\run_all_checks.ps1

23 支自检脚本、900 多条断言，覆盖内核、接口、鉴权、MCP、网页 UI、瓦片坐标、口令备忘、Python 控制台、插件系统等。 跑完会顺手体检：工作区有没有留垃圾、有没有孤儿服务进程、正式实例还活着没有。
